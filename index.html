What makes a car eligible?

  • iDrive 7 (2018-era head unit). iDrive 8, 8.5 and 9 cars can't be coded.
  • BMWs built before March 2021. BMW locked coding on later cars (NCD 2.0 Secure Coding). This doesn't apply to Toyota Supras, so every Supra build year qualifies.
  • Petrol engine only. Diesel, 48V mild-hybrid, plug-in hybrid and electric cars can't be coded.
  • Automatic transmission only.

Heads up: BMW over-the-air software updates can reset the coding. If that happens, we'll need to re-code the feature.
